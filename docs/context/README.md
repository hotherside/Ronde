This is the durable handoff library for Ronde. It separates accepted intent, live implementation, verified evidence and history so another authorised person or tool can continue without a previous chat.

## Authority

- Git and live source are authoritative for committed implementation.
- The working tree may contain newer uncommitted implementation and must be inspected explicitly.
- The product contract is authoritative for intended behaviour.
- Current State records the reviewed reconciliation and uncertainty.
- Notion is a lighter mirror and cannot override the repository.
